# 中英文博客维护指南

本站使用 Astro 内置 i18n 路由扩展 Fuwari，同一仓库提供两套语言入口。界面语言、文章列表和搜索跟随 URL；文章正文分别编写，不会自动翻译。

| 入口 | 内容 |
| --- | --- |
| `/` | 跳转中文首页 `/zh/` |
| `/zh/`、`/en/` | 对应语言的首页 |
| `/zh/archive/`、`/en/archive/` | 对应语言的归档、分类和标签筛选 |
| `/zh/about/`、`/en/about/` | 对应语言的关于页面 |
| `/zh/rss.xml`、`/en/rss.xml` | 各自的文章订阅 |

旧 `/about/`、`/archive/` 入口转到中文版；旧 `/rss.xml` 仍提供中文订阅。静态 GitHub Pages 的页面跳转通过构建产物完成。

## 写文章

```sh
pnpm new-post zh/binary-search
pnpm new-post en/binary-search
pnpm dev
```

两个命令分别创建 `src/content/posts/zh/binary-search.md` 和 `src/content/posts/en/binary-search.md`，初始均为 `draft: true`。省略语言（`pnpm new-post binary-search`）默认放入 `zh/`。

目录决定文章语言。手写文章可省略 `lang`；填写时中文接受 `zh`、`zh_CN`、`zh-CN`，英文使用 `en`。语言与目录不一致、Markdown 位于其他语言目录或 `posts/` 根目录时，构建会报错并指出文件。

图片较多时使用 `pnpm new-post en/binary-search/index`，把图片放在生成的目录中，正文继续使用 `![说明](./diagram.png)`。文章地址为 `/en/posts/binary-search/`，不会包含 `index`。完整字段与图片规则见[写作指南](WRITING.zh-CN.md)。

中英文可以独立发布，没有英文译文的中文文章仍可正常上线。草稿仅在 `pnpm dev` 中展示，不进入生产页面、RSS、搜索或公开译文链接。

## 对应译文与切换

同一相对路径默认互为译文，例如 `zh/notes/example.md` 与 `en/notes/example.md`。如果文件名不同，在两篇文章的 frontmatter 中填写相同的键：

```yaml
translationKey: binary-search-introduction
```

配对键只负责识别对应译文，不改变文章 URL。同一语言不能有两篇文章使用同一个配对键。建议使用稳定、简短的英文标识，配对后不要随意修改。

导航栏的「中文 / English」在文章页优先进入对应译文；没有已发布译文时，进入目标语言首页。首页、关于和归档可以切到对应语言页面；归档的语言专属筛选和分页不会带到另一语言。

跨语言切换使用整页导航，让菜单、侧栏、页面语言和搜索索引一并更新。正文中的跨语言链接也应使用完整语言路径，例如 `/en/posts/binary-search/`；站内同语言链接写 `/zh/posts/binary-search/`。

## 内容与搜索隔离

首页分页、归档、分类标签计数、前后篇导航和 RSS 都只读取当前语言目录中的文章。相同标签名可以在两种语言中分别使用，其计数不会混合。

Pagefind 构建时依据页面的 `<html lang>`（`zh-CN` 或 `en`）生成语言索引，浏览器加载当前语言的索引。查询相同关键词时，中文入口只返回中文页面，英文入口只返回英文页面。没有结果会显示对应语言的提示。开发服务不生成搜索索引，请执行 `pnpm build` 和 `pnpm preview` 验证真实搜索。

每篇文章输出自己的 canonical；仅为实际存在的对应译文输出 `hreflang`，没有译文的首页回退不会被标记成文章译文。更改文章文件名会改变 URL，配对键不会自动创建旧地址重定向。

## 维护与验证

| 位置 | 用途 |
| --- | --- |
| `astro.config.mjs` | Astro i18n 配置，语言前缀与旧入口重定向 |
| `src/i18n/locales.ts` | 支持语言与 HTML 语言标识 |
| `src/i18n/translation.ts`、`src/i18n/languages/` | Fuwari 界面词条 |
| `src/content/spec/zh/about.md`、`src/content/spec/en/about.md` | 中英文关于正文 |
| `src/utils/content-utils.ts` | 目录、语言、译文校验与语言内容查询 |
| `scripts/new-post.js` | 按语言生成草稿 |

```sh
pnpm lint
pnpm check
pnpm test:i18n
pnpm build
pnpm preview
```

双语回归测试在临时目录创建测试文章，覆盖语言隔离、分页、译文、草稿、文章目录图片和搜索索引，测试结束后清理。提交到 `main` 后由现有 GitHub Actions 发布。

实现参考：[Astro 国际化路由](https://docs.astro.build/zh-cn/guides/internationalization/)、[Astro 多语言内容方案](https://docs.astro.build/zh-cn/recipes/i18n/)、[Pagefind 多语言检索](https://pagefind.app/docs/multilingual/)。Fuwari 的文章 `lang` 字段本身不提供这些语言路由和内容分区。
